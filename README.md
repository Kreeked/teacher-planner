# Планер для вчителя

Особистий вебзастосунок вчителя інформатики: календарно-тематичне планування (КТП), розклад і підготовка уроків.
Працює на ПК і телефоні, встановлюється з браузера (PWA) і відкривається без інтернету.

Адреса: https://kreeked.github.io/teacher-planner/

## Як це влаштовано

- **Застосунок:** React + TypeScript + Vite, режим PWA (`vite-plugin-pwa`).
- **Дані:** Firebase Cloud Firestore з локальним кешем — читання й зміни працюють офлайн і синхронізуються самі.
- **Вхід:** Firebase Authentication через Google.
- **Публікація:** GitHub Pages, автоматично після кожного злиття в `main` (`.github/workflows/deploy.yml`).
- **Правила доступу:** `firestore.rules` — кожен бачить лише свої дані в `users/{uid}/…`.

## Запуск на своєму комп'ютері (необов'язково)

Потрібен [Node.js](https://nodejs.org) 22 або новіший.

```bash
npm install
npm run dev
```

Застосунок відкриється на http://localhost:5173.
