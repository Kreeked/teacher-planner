# Планер для вчителя

Особистий PWA учителя інформатики: КТП, розклад, матеріали до уроків (п'ять типів файлів). React + TS + Vite, Firestore з офлайн-кешем, GitHub Pages.
Спілкування, інтерфейс, коміти й PR — українською.

Перед роботою прочитай потрібні файли з [docs/](docs/README.md):
- що робить застосунок і чого в ньому свідомо немає — `docs/overview.md`;
- стек, сервіси, структура коду — `docs/architecture.md`;
- колекції Firestore — `docs/data-model.md`;
- дизайн і правила інтерфейсу — `docs/design.md`;
- команди, емулятори, процес PR — `docs/development.md`.

Перед PR: `npm run lint && npm test && npm run build`. Якщо зміна робить щось у `docs/` неправдою — онови docs у тому ж PR.
